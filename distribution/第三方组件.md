# AuraPet 第三方组件

## 应用

- QtBase 6.12.0，LGPL-3.0。随包 Qt 以独立动态库及插件分发，Qt 源码对应 [025bdad181de241e81bf853c8a2d7bf3d19261a9](https://github.com/qt/qtbase/tree/025bdad181de241e81bf853c8a2d7bf3d19261a9)。Qt 的 LGPL、GPL 原文和供应商 SBOM 同目录保存。发行者应同时提供 LGPL 要求的源码获取及替换方法。
- libavif 1.4.2、AOM 3.15.3、dav1d 1.5.5、libvmaf 3.2.1。随包保存许可原文，库版本取自 Homebrew。项目上游为 [libavif](https://github.com/AOMediaCodec/libavif)、[AOM](https://aomedia.googlesource.com/aom/)、[dav1d](https://code.videolan.org/videolan/dav1d) 和 [VMAF](https://github.com/Netflix/vmaf)。
- 脚本生成的「光团」动画和图标是 AuraPet 的原创演示资源。

## 语音

- [Qwen3-TTS-12Hz-0.6B-Base](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-Base) 及 [Qwen3-TTS-Tokenizer-12Hz](https://huggingface.co/Qwen/Qwen3-TTS-Tokenizer-12Hz) 来自 Qwen 团队。包内或安装器下载的 GGUF 权重是 [Serveurperso 转换与 Q8_0 量化版本](https://huggingface.co/Serveurperso/Qwen3-TTS-GGUF/tree/b7ee2e8c7459c3bea99da23e3d178125a7d1713c)。分发时保持 GGUF 原样，保留 Apache-2.0 许可证及模型与量化来源。
- Metal 运行时使用 [qwentts-cpp-python 0.5.0](https://pypi.org/project/qwentts-cpp-python/0.5.0/)、[qwentts.cpp](https://github.com/ServeurpersoCom/qwentts.cpp) 和其 GGML 运行时。上游使用 MIT 许可。随包保存 Python wheel 的许可与版本元数据。
- Python 使用 [python-build-standalone](https://github.com/astral-sh/python-build-standalone) 的 Apple Silicon CPython 3.12.13 构建。运行时仅保留所需的解释器与标准库，并包含其许可。
- NumPy 使用 [2.5.5](https://github.com/numpy/numpy/tree/v2.5.5)，随包保存 wheel 的许可与版本元数据。

`voice/models.sha256` 记录模型固定提交、文件下载地址和 SHA-256。轻量包中的语音安装器在用户选择后才获取模型。
