# AuraPet 1.0.27 · macOS Apple Silicon

适用范围为原生 arm64，macOS 26.6 或更新版本。本包使用原创桌宠「光团」。现有 AuraPet 本机角色库继续可用，角色包扩展名仍为 `.gifpet`。

## 一键安装

解压后双击「安装 AuraPet.command」，选择「仅安装 AuraPet」或「同时安装千问」。应用安装到当前用户的 `~/Applications`，无需管理员密码。已有 AuraPet 的角色、聊天与语音设置继续读取。

- 轻量包含应用和可选语音安装器。仅安装应用时不下载和启动千问。稍后可以双击「一键安装千问.command」，从 Hugging Face 下载安装固定版本的 GGUF。
- 全量包含应用、Apple Silicon Metal 运行时、千问 0.6B Q8_0 权重和分词器。选择同时安装千问时，使用包内文件，可离线完成。

模型下载和本地拷贝都核对 SHA-256。安装器在本机注册可选语音服务，监听 `127.0.0.1:17860`，登录后启动。若端口已有可用的 AuraPet 千问服务，则复用已有服务和音色配置。

## 启用发音

右键桌宠，打开「回复语音」，勾选「朗读桌宠发言」。使用千问时关闭「使用系统发音」，保留默认服务地址。导入带有中日文参考音色的 `.gifpet`，或者按 `voice/README.md` 添加有权使用的参考录音。全量包里的 Base 模型是音色生成引擎，实际说话音色由参考录音提供。使用系统发音无需千问。
