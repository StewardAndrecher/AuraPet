# 使用手册

## 桌面操作

- 左键拖动角色。聚焦桌宠后按 Esc 或从菜单栏选择退出。
- 短按右键，菜单顶部的「小食与玩具」可装载猫粮、投喂猫薄荷或陪桌宠玩毛线球。悬停在道具上时，卡片底部会显示效果与用法，移开后恢复显示猫粮装载状态。慢食猫粮每秒恢复 3.4 点、运动消耗 6.8 点。高能猫粮每秒恢复 8.5 点、运动消耗 3 点。猫粮同时只生效一种，再点已装载的猫粮可卸下，各角色当前选择会随应用保存。毛线球最多消耗 18 点，猫薄荷最多增加 24 点，活跃度始终为 0–100 点。菜单栏也有这些入口。
- 「灵犀牵引」从桌宠身上按住右键再移向目标。松开后，银灰连线和圆框会淡出，落点短暂亮起星芒。桌宠按当前活跃度起步，活跃度越高，加速和巡航越快；靠近落点时逐步减速，活跃度耗尽也能慢行到达。目标限制在当前屏幕可用区。牵引中可按 Esc 取消，短按右键仍打开菜单，关闭「随机移动」时也可使用牵引。
- 用菜单栏控制显示、隐藏和鼠标穿透。启用穿透后，从菜单栏关闭穿透即可恢复拖拽。
- 「随机移动」默认开启，可以在右键或菜单栏取消勾选。桌宠会在当前屏幕游走、探索、沿边走或停下观察，偶尔和鼠标保持距离跟随，快速接近时短暂后退。它会在接近目标和屏幕边缘时减速，长时间连续移动后短暂停留。拖拽、聊天或隐藏时暂停。
- 活跃度条在 macOS 随聊天输入框一起浮现和收起。导入或切换待机素材后，程序在后台分析图片或 GIF 全部帧的可见区域，将竖条固定在最右可见边缘外侧，长度覆盖整体可见高度。右侧空间不足时贴到角色左侧。槽底采用素材中的代表色，暖黄色填充的尖端带白色星芒。游走和定点移动都消耗同一份活跃度，桌宠可见且静止休息时会回升。
- 「原样导入并播放」直接播放文件已有的图像和动画。内容为 GIF 的 `.agif` 可以直接选取，播放和保存都使用原始文件字节。
- 素材上限为 32 MiB，宽高各最多 4096 像素。默认大小的长边至多 360 逻辑像素，菜单可将角色缩放到默认大小的 50% 至 200%。

## 桌面陪伴

从右键菜单或菜单栏爪印打开「桌面陪伴」。可开始 15、25 或 50 分钟专注，也可自定义 1–180 分钟，均支持暂停、继续和取消。睡眠或重启后，运行中的计时按结束时间校准，暂停时保留剩余时间。

专注结束建议短休息 5 分钟，每完成四轮建议长休息 15 分钟。休息从菜单手动开始，结束后提示可开始下一轮。菜单显示今天完成的专注时长、轮次，以及点击、投喂和发送消息的次数。专注暂停期间仍保持安静，休息期间恢复日常交互。手动「免打扰」可单独开启。

### 键盘和多屏

在「全局快捷键」可以启停 macOS 全局快捷键。⌃⌥A 显示或隐藏桌宠，⌃⌥F 开始 25 分钟专注，⌃⌥D 切换免打扰。选中桌宠后，按 `-`、`+` 每次缩放 10%。聊天框有文字或正在输入法组字时仍按普通字符输入。

「显示器」菜单可选择停留在所在屏幕或固定主屏，也可移动到鼠标所在屏幕。换屏尽量保留相对位置，并吸附到可用工作区的边缘。拔掉桌宠所在的显示器时，会把桌宠调整到剩余屏幕。

## 本地角色库

每次确认导入后，素材会作为新角色保存在应用数据目录中的 `roles.sqlite3`。打开「角色库…」可切换、重命名或删除自定义角色。旧版本保存的当前素材会一次性迁入，名称为「上次导入的素材」。

各角色分别记住桌面位置和缩放比例。拖到屏幕边缘附近时会吸附，恢复时位置会限制在可见屏幕范围内。源文件移动后，可继续使用角色库里的本地副本。

## 分享角色包

在「角色库…」选中角色后，打开「角色分享设置…」直接编辑核心人设，或关联版本 1 的角色卡，选择本机 `voices.json` 里的中日文参考音色，按需添加两个语言的 WAV 语料目录，并设置角色默认猫粮、随机走动和事件动作。投喂、玩耍、双击、专注开始与结束和休息开始与结束可各自绑定动作与固定台词。还可绑定 30 分钟未互动、活跃度降至 20、早间和晚间问候。自动提醒在专注、免打扰或聊天期间暂缓，问候每个角色每天各一次。

点击「导出分享包…」保存一个 `.gifpet` 文件。包内保留原始素材、动作成品以及本版生成的动作模板参数。默认带参考音色及其转写，可勾选「包含完整语音语料」，原录音文件名随语料清单保存。聊天、长期记忆、接口凭证和桌面布局属于本机数据。

可以双击分享包、拖到桌宠或角色列表，或在角色库选「导入角色包…」。预览逐项展示素材、动作、音色、语料和行为规则，并可查看角色的核心提示词，确认后写入角色库。同一角色可更新或保留为副本。更新会保留当前角色的本机聊天与记忆。接收者在自己的语音设置启用千问后可直接使用随包音色。其他人可用轻量版导入、播放及聊天。

角色包是 ZIP。根目录的 `manifest.json` 记录格式版本、角色 ID、动作引用与素材 SHA-256 校验。其他配置分别存于 `role/card.json`、`behavior.json` 与 `voice/`。程序限制包体、文件数量和解压尺寸，导入时只读取支持的文件，验证完毕后通过 SQLite 事务保存。

## 角色动作

右键桌宠打开「角色动作」，为当前角色分别选择待机、开心、困倦素材，并在窗口里预览。待机默认使用角色的原素材，设置后也可恢复。动作素材原样保存在本地角色库，支持现有图片和 GIF 格式。

右键菜单提供「播放开心」「播放困倦」和「回到待机」。动图播放一轮后回到待机，静态动作短暂展示后返回。播放时保持原来的窗口位置和尺寸。

### 从序列帧制作动作

在「角色动作」里选好槽位，再点「导入序列帧」。一次可添加多张 PNG、JPEG 或静态 AVIF，每批按文件名中的数字排序，例如 `走路1.png`、`走路2.png`、`走路10.png`。可以用「上移」「下移」或「移除」调整顺序。

支持 2–120 帧、每秒 1–30 帧。不同大小的图片以底部居中对齐，统一画布的长边最多 512 像素。点「生成预览」查看循环效果，也可切换浅色和深色背景检查透明边缘。调速或调整顺序后需要重新生成预览。

点「保存到待机」「保存到开心」或「保存到困倦」后，生成的 GIF 会替换该槽原素材并保存在本地角色库中。GIF 使用有限色板和二值透明，有底色的源图会保留底色。取消导入会保留槽位原有素材，保存后移动源图片也可以播放。

### 从待机画面生成模板动作

在「角色动作」选好槽位后打开「动作模板」，可以选择轻跳、摇摆或呼吸。程序用当前待机素材的第一帧做整体位移、旋转或缩放；待机是动图时也使用首帧。有底色的图会连同底色一起运动。

可调动作幅度（1–100%）和单轮时长（0.6–4.0 秒）。点「生成预览」检查循环效果，确认后保存到所选槽位。用作待机时会持续循环，用作开心或困倦时会按现有动作规则播放一轮。

## AI 聊天

鼠标悬停桌宠会显示输入框，可以直接移到输入框里点击打字。左键单击桌宠会立即将输入光标放到输入框，按回车发送。已聚焦时移开鼠标可以继续输入，失焦后离开桌宠和输入框会自动收起。靠近屏幕底边、下方空间不足时，输入框会改放在上方。

输入框随系统切换浅色、深色。默认单行，文字变长时先加宽，到达宽度上限后自动换行并增高。Shift＋回车可手动换行。内容超过屏幕内可显示的高度时，可在框内滚动查看完整输入。

回复会逐段显示在白色云朵气泡里。云朵先随文字加宽，再按行增高，保留回复的换行和段落。头顶空间不足时，气泡会改放在桌宠旁边或下方。回复超出气泡容量时，点「查看本条全文」可以滚动、选择和复制，也能继续看正在生成的内容。全文窗口可手动关闭。等待时按 Esc 会停止生成并恢复原输入，其余时候按 Esc 会收起输入框。回复失败时会保留原消息。输入框或气泡显示期间，随机移动会暂停。

双击桌宠会让它主动说一句话。已经配置的 AI 接口可生成发言，接口未配置或不可用时会使用本地短句。

从右键或菜单栏打开「聊天记录」，可以查看当前角色的对话、主动发言和长回复全文，并加载更早记录。在记录窗口的「AI 接口」中填写 OpenAI 兼容服务的 Base URL、模型 ID 和所需的 API Key。API Key 存在 macOS 钥匙串，本地无鉴权接口可留空。

完成的提问和回复一起保存到 `roles.sqlite3`，按角色隔离。主动发言单独标记，只保留桌宠说的话。发送时附带一部分近期对话，聊天内容和选取的上下文会发送至配置的服务。

### 可选回复语音

从右键或菜单栏打开「回复语音…」。「朗读桌宠发言」控制 AI 回复、双击发言和固定短句的声音。「使用系统发音」勾选时直接使用 macOS 系统语音，取消勾选时使用 Qwen3-TTS 0.6B Base。千问连接失败或超时时继续显示完整文字。菜单里的「试听发音」可验证当前选择。首次安装默认关闭语音，免打扰和专注期间静音。「查看本条全文」和聊天记录保留原文。

启动本地服务以及配置中日文音色的步骤见 [可选语音说明](voice/README.md)。

### 自动摘要和长期记忆

在打开输入框、查看聊天记录或完成一轮对话时检查未整理的对话。累计 24 轮、最早可整理对话达到 7 天，或待整理上下文达到 12,000 字符时，会调用已配置的模型整理旧对话。保留最近 8 轮原文用于即时上下文，其他原文仍保存在本地。可关闭「自动整理」，也可在「记忆」窗口点「立即整理旧对话」。

每条长期记忆会显示对应的用户消息和时间。修改或忘记后，相关旧摘要会退出后续聊天上下文，手动改过或忘记的同一记忆不会被下一次整理覆盖。摘要所需的旧对话会发送给你配置的服务。

## 本地静态图抠图

在 macOS 14 或更新版本上，从菜单栏或拖入一张不透明的 PNG、JPEG 或静态 AVIF 时，程序会在本机识别前景并并排显示原图和结果。可以切换深浅背景检查边缘，再选择应用抠图、保留原图或取消导入。

应用静态抠图后，程序会把透明 PNG 保存为当前素材，重启后可直接恢复。识别失败时仍可选择保留原图。

## 本地 GIF 抠图

导入带背景的 GIF 时，预览会显示逐帧处理进度。处理完成后可同步播放原动图和抠图结果，也可以重新播放、切换深浅底色、保留原动图或取消导入。默认光团动图和首帧已透明的素材直接导入。

GIF 抠图最多处理 60 帧。对于长边超过 512 像素的画布，抠图结果会等比缩小到这个尺寸。选择「应用抠图」才编码新的透明 GIF，输出保留播放帧时和循环设置。遇到超出帧数、动图已有透明帧或某帧无法识别主体时，可以保留原动图继续使用。命令行指定的素材直接导入。
