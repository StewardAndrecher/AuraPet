# AuraPet 安装与部署文档

本指南面向希望快速上手 AuraPet 的普通用户以及从源码编译的开发者。AuraPet 本体**不内置任何演示角色**，安装包与角色包完全分离，你可以按需自由组合下载。

## 1. 选择适合你的安装包

前往 [GitHub Releases](https://github.com/StewardAndrecher/AuraPet/releases/latest) 下载对应文件：

| 发行文件 | 大小（约） | 包含内容 | 适用人群 |
| --- | --- | --- | --- |
| **`AuraPet-<版本>-macOS-arm64-Light.zip`**<br>（无千问极简安装包 · macOS） | ~32 MB | AuraPet 桌面主程序、系统语音、角色原声播放、一键安装脚本 | 想轻量体验、日常文字聊天或使用系统发音的 Apple Silicon Mac 用户 |
| **`AuraPet-<版本>-macOS-arm64-Qwen-Offline.zip`**<br>（带千问全量包 · macOS） | ~1.25 GB | 极简版全部内容 + 已校验的 Qwen3-TTS 0.6B Q8_0 GGUF 模型权重 + 千问一键部署脚本 | 想离线直接部署本机高拟真流式角色配音的 Apple Silicon Mac 用户 |
| **`AuraPet-<版本>-Windows-x64-Light.zip`**<br>（无千问极简安装包 · Windows） | ~35 MB | AuraPet Windows 主程序、一键安装脚本（可选配本机千问语音目录） | Windows 10 / 11 x64 用户 |
| **`AuraPet-<版本>-Kaltsit-RolePack.gifpet`**<br>（凯尔希·思衡托角色包 · 可选下载） | ~50 MB | 已获作者授权的凯尔希动图、动作槽、角色卡人设、中日参考音色与语料转写 | 想直接体验完整角色与配音的玩家（**完全可选，按需下载**） |

> 校验文件 `AuraPet-<版本>-SHA256SUMS.txt` 同步提供，如需验证完整性可执行 `shasum -a 256 -c AuraPet-*-SHA256SUMS.txt`。

## 2. 系统要求

- **macOS**：macOS 14.0（Sonoma）或更高版本，**Apple Silicon（M1 / M2 / M3 / M4 系列）**。
  - 若使用「带千问全量包」部署本机千问流式语音，建议可用内存 ≥ 8 GB（16 GB 更流畅），并确保系统已安装 Python 3.12（如未安装可执行 `brew install python@3.12`）。
- **Windows**：Windows 10 / 11 64 位（x64）。

---

## 3. macOS 懒人一键部署

### 方式 A：安装「无千问极简安装包」
1. 下载并解压 `AuraPet-<版本>-macOS-arm64-Light.zip`。
2. 双击解压目录中的 **`安装 AuraPet.command`**。
3. 在弹窗中点击 **「一键安装 AuraPet」**。
4. 脚本会自动完成以下操作并直接启动桌宠：
   - 解除 GitHub 下载的 macOS 隔离属性（`com.apple.quarantine`）；
   - 校验应用签名完整性；
   - 自动安装到 `~/Applications/AuraPet.app`（如果已有旧版，会自动备份后再替换）。

### 方式 B：安装「带千问全量包」
1. 下载并解压 `AuraPet-<版本>-macOS-arm64-Qwen-Offline.zip`。
2. 双击目录中的 **`安装 AuraPet.command`**。
3. 在弹窗中选择 **「同时安装千问」**（如果只想先装桌宠，也可选「仅安装 AuraPet」，日后再双击 `一键安装千问.command` 补装）。
4. 脚本会自动：
   - 安装主程序到 `~/Applications/AuraPet.app`；
   - 离线校验随包附带的两个 GGUF 模型权重（无需重新从 HuggingFace 下载 1.2 GB 大文件）；
   - 配置独立 Python 语音环境并注册用户级后台服务 `com.aurapet.qwen-tts`（监听 `127.0.0.1:17860`）；
   - 等待千问语音服务健康检查通过后自动启动 AuraPet。

> **命令行快捷参数（可选）**：
> - 仅安装应用：`./安装\ AuraPet.command --app-only`
> - 同时安装应用与千问：`./安装\ AuraPet.command --with-voice`
> - 仅安装/修复千问语音：`./安装\ AuraPet.command --voice-only`
> - 国内网络镜像加速：`./安装\ AuraPet.command --with-voice --mirror`

## 4. Windows 懒人一键部署

1. 下载并解压 `AuraPet-<版本>-Windows-x64-Light.zip`。
2. 双击目录中的 **`安装 AuraPet.bat`**。
3. 按窗口提示输入选项并回车：
   - 输入 **`1`**：仅安装 AuraPet 桌面应用；
   - 输入 **`2`**：安装 AuraPet 并同时配置本机千问语音目录。
4. 脚本会自动免管理员安装到 `%LOCALAPPDATA%\AuraPet`，创建桌面与开始菜单快捷方式、注册 `.gifpet` 角色包双击关联并启动应用。

---

## 5. 导入凯尔希·思衡托角色包（或自己的角色）

AuraPet 首次启动时会弹出导入引导（因软件本身无内置角色）：

1. **导入凯尔希·思衡托角色包（可选）**：
   - 从 Releases 下载 `AuraPet-<版本>-Kaltsit-RolePack.gifpet`。
   - **双击 `.gifpet` 文件**，或直接将文件**拖入 AuraPet 窗口 / 角色库**，即可一键导入凯尔希动图、角色卡设定与中日参考音色。
2. **导入任意自定义素材**：
   - 支持透明 GIF、`.agif`、WebP、PNG、JPEG、静态 AVIF。
   - 在 macOS 上，导入带背景的普通图片/GIF 时可使用内置 Apple Vision 智能抠图自动去背景。

## 6. 开发者从源码编译与本地打包

### macOS（Homebrew + Ninja）
```bash
brew install cmake ninja qt@6 libavif libarchive
cmake -S . -B build -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_PREFIX_PATH="$(brew --prefix qt@6);$(brew --prefix libavif);$(brew --prefix libarchive)"
cmake --build build --parallel
ctest --test-dir build --output-on-failure
open build/AuraPet.app
```

**一键生成 macOS 极简包 / 全量包**：
```bash
# 仅生成无千问极简安装包
./distribution/package-macos.sh --ci build/AuraPet.app "$(brew --prefix qt@6)" dist

# 同时生成无千问极简安装包 + 带千问全量包（需先将 GGUF 模型放在 voice/gguf/）
./distribution/package-macos.sh --full-with-models build/AuraPet.app voice/gguf "$(brew --prefix qt@6)" dist
```

### Windows（PowerShell + MSVC + vcpkg）
```powershell
vcpkg install libavif:x64-windows libarchive:x64-windows
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 `
  -DCMAKE_TOOLCHAIN_FILE="$env:VCPKG_INSTALLATION_ROOT/scripts/buildsystems/vcpkg.cmake" `
  -DCMAKE_PREFIX_PATH="C:/Qt/6.7.3/msvc2019_64"
cmake --build build --config Release --parallel
ctest --test-dir build -C Release --output-on-failure
```

## 7. 常见安装问题排查

- **macOS 提示“无法打开，因为无法验证开发者”或右键 `.command` 无权限**：
  - 右键点击 `安装 AuraPet.command` → 选择 **「打开」** 即可通过系统提示运行；或在终端执行 `chmod +x "安装 AuraPet.command" && ./安装\ AuraPet.command`。
- **千问语音启动慢或端口检测未就绪**：
  - 首次启动需要加载模型并预热 Metal 内核，通常需 10–30 秒。可在右键菜单 → **「对话与语音」→「本机千问语音服务…」** 查看运行状态，或检查日志 `~/Library/Application Support/Gif-Pet/Gif-Pet/logs/aurapet-qwen.error.log`。
- **完全卸载**：
  - 删除 `~/Applications/AuraPet.app`；如需清除本地角色库、聊天记录与千问服务，删除 `~/Library/Application Support/Gif-Pet/` 与 `~/Library/LaunchAgents/com.aurapet.qwen-tts.plist`（API Key 位于 `~/Library/Application Support/AuraPet/chat-credentials/`）。
