首个公开技术预览版。面向 Apple Silicon Mac，要求 macOS 26.6 或以上。

- **Light（41 MiB）**。解压双击「安装 AuraPet.command」安装桌宠。可另行一键安装本机千问。
- **Qwen-Offline（约 1.2 GiB）**。自带 Qwen3-TTS 0.6B Base Q8_0 权重、分词器和 Metal 运行时。下载解压后可离线安装。
- **SHA256SUMS.txt**。可核对两个归档的文件完整性。

默认角色为原创光团。参考录音可从用户有权使用的音色配置或 `.gifpet` 角色包导入。素材、聊天 API 和千问使用说明见 [README](https://github.com/StewardAndrecher/AuraPet#安装)。

当前安装包使用 macOS 临时签名，作为技术预览分发。正式签名、公证和干净 Mac 的分发验收仍待完成。
